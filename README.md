# Crossfire

A 3D multiplayer browser shooter. Up to eight players share a room, with three weapons, server-checked hits, jumping, sprinting, respawns, and five-minute free-for-all rounds. A separate practice mode includes three labelled bots.

The application lives in [crossfire/](crossfire/). See its [setup instructions](crossfire/README.md) to run locally or deploy. From this directory, `npm run dev`, `npm run build`, and `npm test` forward to the application.

Created in [T3 Code](https://t3.codes).
